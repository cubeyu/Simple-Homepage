## 项目分析：Simple-Homepage（水墨小筑）UI 综合优化

完成全仓代码审阅（Vue 3.5 + Vite 7 + Iconify，纯 CSS 水墨风个人主页），产出 `UI优化分析报告.md`。

核心发现（已用 grep 核实）：
- **P0 可访问性**：主题切换是 `<div @click>`（Header.vue）非 button，键盘不可切换、无焦点样式；`.linkBtn` 无 `:focus-visible`；全局 `cursor:none` 无 JS 降级；`config.json` 的 `age:"Null"` 渲染 bug。
- **P1 健壮/性能**：favicon 引用 `/src/favicon.ico` 构建后 404（应放 public/）；Iconify 运行时联网取图标；`feTurbulence` 双层噪点性能开销；主题切换 FOUC（`onMounted` 后才设 body theme）；墨水拖尾频繁建删 DOM。
- **P2 工程化**：`MainCard.css` 被 5 个组件各自 `@import`（非 scoped）；死代码 `animate-float`、LinkBtn 的 `hoverColor`/`--btn-hover-color`、`@keyframes fadeInUp/scrollUnroll/inkSpread` 未使用；CustomCursor 用 setTimeout 500ms 后 querySelectorAll 绑事件。
- **P3 视觉/内容**：绝对定位魔法数字易重叠；5 个"测试应用"占位链接；`province:"China"` 突兀；装饰元素偏多。

用户仅要"分析与方案"，未要求实现。下一步按 P0→P3 实施。

## 布局微调：左侧栏（计划 + 时光）内缩
- 反馈：左「我的一些鸽子计划」压到左侧竖排诗句「山不在高有仙则名」；下方「时光」模块需与上方左栏对齐。
- 根因：`.content` 仅依赖 mainCard 内边距（48px），在 ≤992px 时内边距收窄至 32px，竖排诗句（left:12px，宽约 19–24px，止于 ~31–36px）与左栏内容间距不足甚至重叠。
- 修复：给 `.mainCard .content` 加 `padding-inline: 1.5rem`（桌面），≤992px 提到 `2rem`，≤768px 重置 `0`（移动端已隐藏诗句）。两行 .content-row 的 .leftBox 共享此内缩，左右两模块保持同左缘、互相对齐，且对称避开左右诗句。
- 验证：`npm run build` 通过（35 模块）。typew 横幅随之内缩与两行对齐；若希望 typew 保持满宽可改为仅给 .content-row 加 padding。

## 技术栈图标：切换为 skillicons.dev
- 需求：个人简介（rightBox 内 TechStack「我的一些技术栈」）的技能图标改用 skillicons.dev。
- 验证 URL 模式：`https://skillicons.dev/icons/vue.svg` → 404；`https://skillicons.dev/icons?i=vue` → 200 image/svg+xml。故采用 query 端点逐图标加载。14 个 slug 全部为 skillicons.dev 标准名（html5/css3/javascript/markdown/mysql/php/python/vue/nodejs/nextjs/vite/tailwind/java/jquery）。
- 改动：
  1. `src/config/techStack.json`：每个 `icon` 由 Iconify 名改为 skillicons.dev slug。
  2. `src/components/TechStack.vue`：移除 `@iconify/vue`，改用 `<img :src="'https://skillicons.dev/icons?i='+slug">`；加 `reactive(Set)` 失败回退——图片 onerror 时显示技术名文字（`.techFallback`），避免坏图破版；`alt` 取技术名（可访问性优于原 aria-hidden）。
  3. `src/assets/css/MainCard.css`：原 `.iconify` 灰度/sepia 滤镜迁移到 `.skill-icon`（保持水墨基调统一，hover 还原品牌色），新增 `.techFallback` 样式。
  4. `index.html`：新增 `preconnect https://skillicons.dev`。
- 验证：`npm run build` 通过（35 模块）。说明：skillicons.dev 为运行时远程彩色图标（与原 Iconify 同类取舍）；沿用原设计的 grayscale 滤镜使其融入水墨风，如想完全彩色可去掉该 filter。

## 反馈修复：skillicons 缺图标 + 多终端响应优化
- 反馈：HTML、CSS 两个图标不显示；需要调整多终端设备查看的响应布局。
- 根因：
  1. 我错误地使用了 `html5` / `css3` 作为 slug，但 skillicons.dev 的有效 slug 是 `html` / `css`（该站点对无效 slug 会返回 200 的占位/空 SVG，所以之前的 200 验证没发现）。
  2. 小屏/超窄屏设备上字号、图标、间距、内边距等没有足够细的适配，且部分弹性容器缺少 `min-width: 0` / `overflow-wrap`，存在溢出风险。
- 改动：
  1. `src/config/techStack.json`：HTML slug 从 `html5` 改为 `html`，CSS slug 从 `css3` 改为 `css`。
  2. `src/assets/css/MainCard.css`：
     - 给 `.content .leftBox`、`.header .sayHi` 加 `min-width: 0`；给 `.sayHi`、`.card p/span`、`.typewriter` 加 `overflow-wrap: break-word`，防止小屏文本溢出。
     - 992px 断点：将 `.content` 的 `padding-inline` 从 3rem 降到 2.5rem，在避开两侧诗句的同时给内容留更多空间。
     - 480px 断点：技能图标从 48px 缩到 42px，`.skill-icon` 缩到 30px。
     - 新增 360px 超窄屏断点：卡片内边距 1.2rem/1rem、头像 4rem、标题 1.15rem/名字 1.35rem、技能图标 38px/ skill-icon 28px、链接按钮 12px 字高 34px、打字机 12px，整体更紧凑。
- 验证：`npm run build` 通过（35 模块）。已通过 curl 检查 `https://skillicons.dev/icons?i=html` 和 `?i=css` 返回有效 SVG。
