# 十六次调整：PC / 平板（横屏）全屏无滚动

## 完成内容

已修复网站在 PC / 平板横屏全屏模式下仍需上下滚动的问题。

- **改动文件**：`src/assets/css/MainCard.css`
- **作用范围**：仅对 `min-width: 769px`（桌面 + 平板横屏）生效；≤768px 的手机 / 竖屏平板保持原样，仍保留自然滚动。
- **核心策略**：
  1. 对 PC / 平板横屏设置 `html, body { height:100%; overflow:hidden; }`，彻底杜绝整页滚动条。
  2. 压缩 `.mainCard` 及内部组件的 margin / padding / gap / 字体 / 头像尺寸 / todoList 最大高度，使整卡高度刚好适配常见桌面 / 平板视口。
  3. 保留水墨装饰与古风标题（光阴 / 百工 / 待办 / 纵览 + 方胜装饰）。
